Deepline Assistant wireframes

Every step a rep goes through, drawn at real panel width with real copy, in the Deepline app's own tokens: silver surfaces, monochrome buttons, colour only for status, Geist at 14 and 16 px. Each frame lists what to look at and the rubric criteria it is built to win. Dashed frames are later scope, shown so you can approve or cut them.

What we decided

Existing data firstThe page card shows rows already in your table before any paid button. A completed result turns the primary button into “Refresh”.
Only my rowsThe card and My table show your own lookups. No team rows, no CRM lookup before a run.
Cost on the button, confirm above 25 creditsButtons carry the estimate. Runs that may cost more than 25 credits ask once, inside the panel.
Search import with a capSearch and list pages import up to a number you set (default 25). Deepline fetches the results; the page is never read.
Admin-chosen handoffsPlays an admin marks as handoffs (“Create HubSpot contact”, “Add to lemlist”) appear on a finished row and link to the created record.
URL and title onlyNo scripts on any page. The detected entity is shown in the card so a wrong match is visible.
